## 2. 速度调参优化清单

### 目标

```text
固定赛道优先速度
减少精调和等待
减少远距离障碍物对速度的影响
在可控范围内提高通过速度
```

### 方向一：提高主控手动移动速度

文件：

```text
src/robot_slam/scripts/competition_control.py
```

当前主控中部分直接 `/cmd_vel` 速度偏低：

```python
FINE_ADJUST_MAX_SPEED = 0.10
RELAY_MAX_VX = 0.10
RELAY_MAX_VY = 0.24
BACK_PUSH_SPEED = 0.14
END_SLIDE_SPEED = 0.14
```

建议尝试：

```python
FINE_ADJUST_MAX_SPEED = 0.15  # 或 0.18
RELAY_MAX_VX = 0.16          # 或 0.20
RELAY_MAX_VY = 0.30          # 或 0.35
BACK_PUSH_SPEED = 0.20
END_SLIDE_SPEED = 0.20
```

### 方向二：减少任务点精调时间

文件：

```text
src/robot_slam/scripts/competition_control.py
```

建议关注：

```python
SHOOT_TASK_DIST_TOL
TASK_NAV_TOL
SHOOT_XY_TOL
TASK_NAV_TIMEOUT
```

优化方向：

```text
适当放宽到点容差
减少为了最后几厘米反复精调
让 move_base 大致到位即可
由视觉瞄准负责最后射击精度
```

### 方向三：提高 DWA 最大平移速度

文件：

```text
src/robot_slam/params/carto/dwa_local_planner_params.yaml
```

当前：

```yaml
max_vel_trans: 0.4
```

建议尝试：

```yaml
max_vel_trans: 0.5
```

如果实车稳定，再尝试：

```yaml
max_vel_trans: 0.6
```

### 方向四：降低远距离障碍物影响

文件：

```text
src/robot_slam/params/carto/costmap_common_params.yaml
```

当前：

```yaml
obstacle_range: 3.0
raytrace_range: 3.5
```

建议尝试：

```yaml
obstacle_range: 1.2 ~ 1.8
raytrace_range: 1.5 ~ 2.2
```

作用：

```text
避免小车很早就因为远处障碍减速
减少不必要的提前绕行和停顿
```

### 方向五：缩短 DWA 预测时间

文件：

```text
src/robot_slam/params/carto/dwa_local_planner_params.yaml
```

当前：

```yaml
sim_time: 2.0
stop_time_buffer: 0.2
```

建议尝试：

```yaml
sim_time: 1.0 ~ 1.5
stop_time_buffer: 0.05 ~ 0.1
```

作用：

```text
减少局部规划过度保守
提高小车在窄路和障碍附近的通过速度
```

### 方向六：减少中继点 yaw 校正等待

文件：

```text
src/robot_slam/scripts/competition_control.py
```

建议关注：

```python
RELAY_YAW_TOL
RELAY_YAW_HARD_LIMIT
BACK_YAW_TOL
```

优化方向：

```text
适当放宽角度容差
减少原地转向等待
保证能过窄通道即可
```

### 方向七：提高终点滑入速度

文件：

```text
src/robot_slam/scripts/competition_control.py
```

当前：

```python
END_PRE_SPEED = 0.14
END_SLIDE_SPEED = 0.14
END_RETRY_SPEED = 0.08
```

建议尝试：

```python
END_PRE_SPEED = 0.20
END_SLIDE_SPEED = 0.20
END_RETRY_SPEED = 0.12
```

### 调参原则

```text
优先调主控直接 cmd_vel 速度
再调 DWA 最大速度
再调 costmap 障碍影响
每次只改一组参数，实车观察是否明显提速
如果出现冲过头，再略微回退速度或容差
```
