## 一、Python 代码规范

### 1.1 Shebang

所有 Python 脚本使用 Python 2 解释器：

```python
#!/usr/bin/env python2
# -*- coding: utf-8 -*-
```

原因：ROS Melodic 官方仅支持 Python 2。

### 1.2 中文编码

Python 2 的 `str` / `unicode` 不兼容中文格式化。统一使用 `_safe()` 函数处理：

```python
def _safe(s):
    """Safe str for Python 2: encode unicode to utf-8 bytes"""
    if isinstance(s, unicode):
        return s.encode('utf-8')
    return str(s)
```

- **日志消息**：全部使用英文，中文名称通过 `_safe(name)` 转换后输出
- **Topic 数据**：不做编码转换，直接透传

### 1.3 Global 变量

射击相关的跨线程标志位使用模块级 `global`：

```python
point_msg = None
target_id_rotating = None
target_id_moving = None
should_attack_circular = False
should_attack_rotating = False
should_attack_moving = False
```

原因：callback 与主循环之间共享状态，ROS Melodic 没有原生的线程安全队列可用。

### 1.4 执行权限

`competition_control.py` 等脚本每次 `git pull` 后需要重新 `chmod +x`：

```bash
chmod +x src/robot_slam/scripts/competition_control.py
```

## 二、导航容差标准

### 2.1 常量定义

```python
SHOOT_FAST_ACCEPT_DIST = 0.08   # FAST_ACCEPT 最大距离 (m)
SHOOT_YAW_TOL = 15.0            # yaw 容差 (deg)
SHOOT_TASK_DIST_TOL = 0.10      # TASK 入口距离容差 (m)，与 _in_task_zone 一致
```

### 2.2 两级导航精度

| 阶段 | 方法 | 容差 | 超时 | 用途 |
|------|------|------|------|------|
| 粗定位 | `goto()` | 0.12m (task) / 0.25m (relay) | 15s / 20s | move_base 导航到目标附近 |
| 精调 | `_fine_adjust_to_pose()` | 0.05m / 10° yaw | 10s | cmd_vel 修正位置+朝向 |

### 2.3 到达判定优先级

1. **FAST_ACCEPT**：粗定位后，同时满足 dist ≤ 0.08m + yaw_err ≤ 15° + in_task_zone → 跳过精调
2. **FINE_ADJUST**：不满足 FAST_ACCEPT → 先修 XY（锁定 yaw），再修 yaw
3. **TASK_PRE_CHECK**：进入射击前最终验证 dist + yaw + in_zone
4. **YAW_RETRY**：仅 yaw 不合格时，额外一次旋转修正机会

### 2.4 途经点出发航向

途经点到达后**不使用 YAML 中的固定 yaw**，而是实时计算到下一个点的方向：

```python
heading_deg = atan2(next_y - robot_y, next_x - robot_x)
rotate_to_yaw(heading_deg, tol_deg=10.0)
```

途经点负责**出发方向**，射击点负责**最终瞄准**。

## 三、日志标签规范

所有 `rospy.loginfo` / `logwarn` / `logerr` 使用统一的标签前缀：

| 标签 | 含义 | 示例 |
|------|------|------|
| `[TASK_PRE]` | 射击点预到达状态 | `[TASK_PRE] 射击点2 target=(...) robot=(...)` |
| `[ARRIVE]` | 粗定位到达判定 | `[ARRIVE] OK dist=0.116 tol=0.120` |
| `[FAST_ACCEPT]` | 快速接受判定 | `[FAST_ACCEPT] REJECT dist=0.116 in_zone=False` |
| `[FINE_ADJUST]` | 精调过程 | `[FINE_ADJUST] xy OK dist=0.003` |
| `[ROTATE]` | 原地旋转 | `[ROTATE] to -33deg from 5deg` |
| `[TASK]` | 射击任务 | `[TASK] Done: 射击点2-旋转靶` |
| `[RELAY]` | 途经点 | `[RELAY] departure heading to 射击点2: -33deg` |
| `[END]` | 终点滑入 | `[END] Slide complete, dist=0.003` |

## 四、状态机规范

### 4.1 主状态（competition_control）

```
WAIT_START → VOICE_RECV → NAV_LOOP → FINISH
```

- **WAIT_START**：发布 `/initialpose`，等待人工确认（Enter 键）
- **VOICE_RECV**：触发语音识别，18s 后进入导航
- **NAV_LOOP**：遍历 `route_points`，按 type 分发处理
- **FINISH**：取消所有导航，停止运动，退出

### 4.2 路线点类型

| type | 行为 | 容差 |
|------|------|------|
| `relay` | 到达 + 动态出发航向 | 0.25m |
| `task` | 粗定位 → FAST_ACCEPT/精调 → TASK 预检 → 射击 | 见 §2.3 |
| `end` | 导航到 pre_point → cmd_vel 低速滑入 | 0.05m |

### 4.3 状态发布

主控通过 `/competition_state` topic 发布当前状态（String），供 `competition_monitor` 订阅。

## 五、坐标系与 TF

### 5.1 参考系

- **map**：AMCL 校正后的绝对坐标系，所有导航目标使用此坐标系
- **base_link**：机器人本体坐标系，用于获取当前位置

### 5.2 位置获取

机器人位置通过 TF 从 `map` → `base_link` 获取，**不信任 odom**：

```python
self.tf_listener.waitForTransform('map', 'base_link', rospy.Time(0), rospy.Duration(0.5))
trans, _ = self.tf_listener.lookupTransform('map', 'base_link', rospy.Time(0))
self.robot_x = trans[0]
self.robot_y = trans[1]
```

### 5.3 Yaw 获取

```python
_, rot = self.tf_listener.lookupTransform('map', 'base_link', rospy.Time(0))
_, _, yaw = tf.transformations.euler_from_quaternion(rot)
```

## 六、导航接口

### 6.1 发送目标

使用 `/move_base_simple/goal` topic（与 RViz "2D Nav Goal" 相同），**不使用** actionlib 的 `send_goal()`：

```python
goal = PoseStamped()
goal.header.frame_id = 'map'
goal.pose.position.x = x
goal.pose.position.y = y
# ... set orientation ...
self.goal_pub.publish(goal)
```

原因：actionlib 在 costmap 阻挡时会提前 abort，而 topic 方式只负责发送目标，到达判定由自己控制。

### 6.2 取消导航

```python
self.move_base.cancel_all_goals()
```

### 6.3 自行到达判定

不依赖 move_base 的 result，而是用 TF 轮询位置自行判断：

```python
while d >= tol:
    self._update_robot_pose()
    d = math.hypot(robot_x - x, robot_y - y)
    rate.sleep()
```

## 七、射击接口

### 7.1 串口协议

- 端口: `/dev/shoot`
- 波特率: 9600, 8N1
- 开火: `0x55 0x01 0x12 0x00 0x00 0x00 0x01 0x69`
- 停火: `0x55 0x01 0x11 0x00 0x00 0x00 0x01 0x68`

### 7.2 Dry-run 模式

`/dev/shoot` 不可用时自动进入 dry-run 模式，跳过射击等待，日志输出 `[TASK] Dry-run, skip shoot`。

### 7.3 靶子类型

| target_type | 传感器 | Topic | 瞄准方式 |
|-------------|--------|-------|----------|
| `circular` | 模板匹配 | `/object_position` | P 控制器 angular.z = -0.02 * offset_x |
| `rotating` | AR tag | `/ar_pose_marker` | P 控制器 angular.z = -1.0 * ax |
| `moving` | AR tag | `/ar_pose_marker` | P 控制器 angular.z = -0.95 * ax |

## 十、Git 规范

### 10.1 仓库结构

- **Git 仓库**：包含完整比赛 workspace (`ros_shoot_2026`) 的源码

- `main`：稳定版本
