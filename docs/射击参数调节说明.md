# 2026 射击参数调节说明

射击参数集中在：

`src/robot_slam/scripts/competition_control.py`

搜索 `Shooting Manual Tuning` 即可找到全部参数。修改参数后需要重启
`competition_control`。建议每次只修改一个参数，并记录修改前后的现象。

## 一、目标 ID 来源

旋转靶与移动靶的打击 ID 仅来自语音节点：

```text
语音识别
→ shoot_2026_voice.py 解析文本
→ /target_id_rotating 或 /target_id_moving
→ competition_control.py
```

- 旋转靶只接受 `1~5`。
- 移动靶只接受 `6~8`。
- 未收到两个合法语音 ID 时，主控不会进入导航路线。
- YAML 不再提供目标 ID，也没有无语音回退模式。

`CIRCULAR_VISION_TARGET_ID` 是模板匹配节点输出的视觉类别编号，不是语音指定的
打击 ID。

## 二、串口与开火参数

| 参数 | 当前值 | 作用 | 调大或修改后的影响 |
|---|---:|---|---|
| `SHOOT_SERIAL_PORT` | `/dev/shoot` | 射击机构串口设备 | 仅在设备名变化时修改 |
| `SHOOT_SERIAL_BAUDRATE` | `9600` | 射击串口波特率 | 必须与下位机一致 |
| `SHOOT_FIRE_DURATION` | `0.09s` | 发射命令到停止命令之间的持续时间 | 增大可能提高发射力度，但会增加机构负载和连续发射风险 |

## 三、环形靶参数

环形靶使用 `/object_position`。其中 `x` 为图像像素坐标，`z` 为视觉模板编号。

| 参数 | 当前值 | 作用 | 增大后的影响 |
|---|---:|---|---|
| `CIRCULAR_VISION_TARGET_ID` | `52` | 需要跟踪的视觉模板编号 | 不是连续调节量，必须与模板匹配输出一致 |
| `CIRCULAR_AIM_CENTER_X` | `320px` | 图像瞄准中心 | 瞄准中心向图像右侧移动 |
| `CIRCULAR_FIRE_THRESHOLD_PX` | `10px` | 允许开火的水平误差 | 更容易开火，但瞄准精度降低 |
| `CIRCULAR_STABLE_FRAMES_REQUIRED` | `1` | 连续满足开火误差的帧数 | 抗抖动更强，但开火更慢 |
| `CIRCULAR_KP_FAR` | `0.02` | 偏差较大时的旋转 P 增益 | 转向更快，过大容易来回振荡 |
| `CIRCULAR_KP_NEAR` | `0.012` | 接近中心时的旋转 P 增益 | 中心附近修正更快，过大容易越过中心 |
| `CIRCULAR_NEAR_THRESHOLD_PX` | `40px` | 远近 Kp 的切换边界 | 更大范围使用较小的近距 Kp，运动更柔和 |
| `CIRCULAR_MAX_WZ` | `0.65rad/s` | 最大旋转速度 | 搜索与大偏差修正更快，但更容易过冲 |
| `CIRCULAR_MIN_WZ` | `0.08rad/s` | 非零修正时的最小旋转速度 | 更容易克服底盘死区，但小误差时更容易过冲 |
| `CIRCULAR_SEARCH_WZ` | `0.18rad/s` | 未检测到模板时的搜索旋转速度 | 搜索更快，但可能错过目标 |

## 四、旋转靶参数

旋转靶使用 `/ar_pose_marker`，根据语音指定的 AR 标签 ID 进行瞄准。

当前默认启用预测固定射击门：

```text
静止观察目标 ID 的 x 运动方向
→ 预测它下一次先到达三点钟还是九点钟
→ 机器人转向对应固定射击门
→ 保持静止，等待目标进入准星与 y 窗口
→ 开火
```

原有持续追踪逻辑仍保留。模式切换：

| 参数值 | 行为 |
|---|---|
| `ROTATING_AIM_MODE = "predictive_gate"` | 启用预测三点钟/九点钟射击门 |
| `ROTATING_AIM_MODE = "legacy_track"` | 使用旧版持续追踪目标到准星中心 |

### 4.1 两种模式共用参数

| 参数 | 当前值 | 作用 | 增大后的影响 |
|---|---:|---|---|
| `ROTATING_X_THRESHOLD` | `0.14` | 允许开火的 AR 标签水平误差 | 更容易开火，但水平瞄准精度降低 |
| `ROTATING_Y_MIN` | `-0.78` | 允许开火的 y 窗口下限 | 数值增大将缩小或移动开火窗口，需结合 `Y_MAX` 调整 |
| `ROTATING_Y_MAX` | `-0.69` | 允许开火的 y 窗口上限 | 数值增大将扩大或移动开火窗口 |
| `ROTATING_STABLE_FRAMES_REQUIRED` | `1` | 连续满足 x、y 条件的帧数 | 抗误触发更强，但可能错过旋转靶开火时机 |
| `ROTATING_KP_FAR` | `0.55` | 偏差较大时的旋转 P 增益 | 跟踪更快，过大容易振荡 |
| `ROTATING_KP_NEAR` | `0.35` | 接近中心时的旋转 P 增益 | 精调更快，过大容易越过中心 |
| `ROTATING_NEAR_THRESHOLD` | `0.18` | 远近 Kp 切换边界 | 更大范围使用较小的近距 Kp |
| `ROTATING_MAX_WZ` | `0.30rad/s` | 最大旋转速度 | 跟踪更快，但运动更激进 |
| `ROTATING_MIN_WZ` | `0.04rad/s` | 最小旋转速度 | 更容易克服底盘死区，但小误差时可能抖动 |
| `ROTATING_SHOOT_COOLDOWN` | `0.20s` | 开火后回调保持时间 | 增大可减少连续触发风险，但延长任务时间 |

`ROTATING_Y_MIN <= marker_y <= ROTATING_Y_MAX` 时，y 条件才算满足。

### 4.2 预测固定射击门参数

| 参数 | 当前值 | 作用 | 调整影响 |
|---|---:|---|---|
| `ROTATING_PERIOD_SEC` | `26.0s` | 旋转靶一圈时间的参考值，用于日志和估算最大等待约半圈 | 按现场实测周期修改 |
| `ROTATING_GATE_OBSERVE_SEC` | `0.8s` | 判断目标运动方向前的最短观察时间 | 增大后方向判断更稳定，但耗时增加 |
| `ROTATING_GATE_MAX_OBSERVE_SEC` | `2.0s` | 方向不明显时的最大观察时间 | 到时后选择当前位置更接近的一侧 |
| `ROTATING_GATE_MIN_SAMPLES` | `4` | 判断方向所需的最少连续观测数 | 增大后更抗噪，但需要更高回调频率和更长时间 |
| `ROTATING_GATE_MIN_X_DELTA` | `0.015` | 判断目标确实向左或向右运动的最小 x 变化量 | 增大可减少噪声误判，但转折点附近更难判断 |
| `ROTATING_GATE_LEFT_YAW_OFFSET_DEG` | `8°` | 九点钟固定射击门相对任务点 yaw 的偏移 | 必须现场标定 |
| `ROTATING_GATE_RIGHT_YAW_OFFSET_DEG` | `-8°` | 三点钟固定射击门相对任务点 yaw 的偏移 | 必须现场标定 |
| `ROTATING_GATE_YAW_TOL_DEG` | `2°` | 机器人到达固定射击门朝向的 yaw 容差 | 增大后更快开始等待，但射击门位置误差增大 |
| `ROTATING_GATE_TURN_KP` | `1.0` | 转向固定射击门的 P 增益 | 增大后转向更快，过大容易过冲 |
| `ROTATING_GATE_MAX_WZ` | `0.35rad/s` | 转向射击门时最大角速度 | 增大后转向更快 |
| `ROTATING_GATE_MIN_WZ` | `0.06rad/s` | 转向射击门时最小角速度 | 增大后更容易克服死区，但接近目标 yaw 时可能抖动 |
| `ROTATING_GATE_FIRE_X_THRESHOLD` | `0.08` | 固定门模式允许开火的标签水平误差 | 增大后更容易开火，但精度降低 |
| `ROTATING_GATE_STABLE_FRAMES_REQUIRED` | `2` | 固定门内连续满足开火条件的帧数 | 增大后抗误触发更强，但可能错过目标 |

左右 yaw 偏移的 `8°/-8°` 只是初始值。现场应让机器人分别瞄准三点钟和九点钟，
记录相对任务点正前方所需的 yaw 偏移，再替换这两个参数。

预测逻辑根据连续观测的 `marker.position.x` 变化方向选择目标下一次先到达的侧门。
接近三点钟或九点钟转折点时，x 方向可能不明显，此时会在最大观察时间后选择
当前位置更接近的一侧。

## 五、移动靶参数

移动靶使用 `/ar_pose_marker`，根据语音指定的 AR 标签 ID 进行瞄准。

| 参数 | 当前值 | 作用 | 增大后的影响 |
|---|---:|---|---|
| `MOVING_X_THRESHOLD` | `0.10` | 允许开火的水平误差 | 更容易开火，但瞄准精度降低 |
| `MOVING_STABLE_FRAMES_REQUIRED` | `2` | 连续满足开火条件的帧数 | 抗抖动更强，但可能错过高速目标 |
| `MOVING_KP_FAR` | `0.95` | 偏差较大时的旋转 P 增益 | 追踪更快，过大容易振荡 |
| `MOVING_KP_NEAR` | `0.70` | 接近中心时的旋转 P 增益 | 中心附近追踪更快，过大容易过冲 |
| `MOVING_NEAR_THRESHOLD` | `0.18` | 远近 Kp 切换边界 | 更大范围使用较小的近距 Kp |
| `MOVING_MAX_WZ` | `0.60rad/s` | 最大旋转速度 | 更容易追上快速目标，但底盘运动更激进 |
| `MOVING_MIN_WZ` | `0.08rad/s` | 最小旋转速度 | 更容易克服死区，但中心附近可能抖动 |
| `MOVING_SHOOT_COOLDOWN` | `0.10s` | 开火后回调保持时间 | 增大可减少重复触发风险 |

## 六、常见现象与调整方向

| 现象 | 优先调整 |
|---|---|
| 目标中心附近来回振荡 | 降低对应 `KP_NEAR` 或 `MIN_WZ` |
| 偏差较大时跟踪太慢 | 增大对应 `KP_FAR` 或 `MAX_WZ` |
| 已经对准但不发射 | 适当增大 `*_X_THRESHOLD`，旋转靶同时检查 y 窗口 |
| 未完全对准就发射 | 减小 `*_X_THRESHOLD`，增加 `*_STABLE_FRAMES_REQUIRED` |
| 移动靶总是追不上 | 增大 `MOVING_KP_FAR` 或 `MOVING_MAX_WZ` |
| 底盘小误差时完全不动 | 增大对应 `MIN_WZ` |
| 底盘小误差时持续抖动 | 减小对应 `MIN_WZ` 或 `KP_NEAR` |

参数调整后应先断开发射机构或进入可控测试环境，确认底盘瞄准行为正常，再连接真实射击机构。
