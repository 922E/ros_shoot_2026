# 2026 射击挑战赛 — 完整操作流程

> 工作空间路径: `~/freeze_ros/ros_shoot_2026`

## 一、硬件检查（每次开机）

确认 USB 线没有插混：
- 左上方 USB → 激光雷达
- 橙色 USB → 射击模块
- HDMI 线严禁热插拔

```bash
# 查看串口设备
ls /dev/abot /dev/shoot /dev/rplidar
```

## 二、首次环境准备（只做一次）

```bash
# 拉取最新代码
```

## 三、标定路线坐标（场地不变只做一次）

### 3.1 启动导航

```bash
# 终端 1: 启动底盘
source ~/abot_ws/devel/setup.bash
source ~/freeze_ros/ros_shoot_2026/devel/setup.bash
roslaunch abot_bringup robot_with_imu.launch

# 终端 2: 启动导航（加载你建好的地图）
source ~/abot_ws/devel/setup.bash
source ~/freeze_ros/ros_shoot_2026/devel/setup.bash
# 先把 my_lab_freeze 地图放到 robot_slam/maps/ 下
roslaunch robot_slam navigation_shoot.launch
```

### 3.2 用键盘控制小车走到每个任务点

```bash
# 终端 3: 键盘控制
sudo apt install ros-melodic-teleop-twist-keyboard -y   # 首次安装
rosrun teleop_twist_keyboard teleop_twist_keyboard.py
```

### 3.3 记录坐标

把小车精确停到每个任务点区域内（38cm × 32cm），然后：

```bash
# 查看当前 map 坐标
rostopic echo /amcl_pose -n 1 | grep position
```

把 x, y 值填入 `src/robot_slam/config/competition_2026_route.yaml` 中对应点的坐标。

**需要标定的点：**
- 起点位置
- 中继点 A、B、C、D（合理路径，避开禁行区和围挡）
- 任务点 1 中心 + 四个边界
- 任务点 2 中心 + 四个边界
- 任务点 3 中心 + 四个边界
- 终点位置

标定完成后推送到 GitHub。

## 四、比赛启动（每次比赛执行）

```bash
# === 终端 1: 竞赛主控 + 监控 ===
source ~/abot_ws/devel/setup.bash
source ~/freeze_ros/ros_shoot_2026/devel/setup.bash
roslaunch robot_slam competition_2026.launch
```

然后依次在新终端启动依赖节点：

```bash
# === 终端 2: 底盘 ===
source ~/abot_ws/devel/setup.bash
source ~/freeze_ros/ros_shoot_2026/devel/setup.bash
roslaunch abot_bringup robot_with_imu.launch

# === 终端 3: 导航 ===
source ~/abot_ws/devel/setup.bash
source ~/freeze_ros/ros_shoot_2026/devel/setup.bash
roslaunch robot_slam navigation_shoot.launch

# === 终端 4: 摄像头 + 射击 ===
source ~/abot_ws/devel/setup.bash
source ~/freeze_ros/ros_shoot_2026/devel/setup.bash
roslaunch track_tag usb_cam_with_calibration.launch
# 射击模块初始化
roslaunch abot_bringup shoot.launch

# === 终端 5: AR 标签检测 ===
source ~/abot_ws/devel/setup.bash
source ~/freeze_ros/ros_shoot_2026/devel/setup.bash
roslaunch track_tag ar_track_camera.launch

# === 终端 6: 模板匹配 ===
source ~/abot_ws/devel/setup.bash
source ~/freeze_ros/ros_shoot_2026/devel/setup.bash
roslaunch abot_find find_object_2d_shoot.launch

# === 终端 7: 语音模块 ===
source ~/abot_ws/devel/setup.bash
source ~/freeze_ros/ros_shoot_2026/devel/setup.bash
rosrun TTS_audio TTS.py &
rosrun robot_slam 2026_shoot_target.py &
python3 $HOME/freeze_ros/ros_shoot_2026/src/robot_slam/scripts/2026_shoot_demo.py &
```

所有节点启动完毕后，在 competition_control 终端输入 `1`，比赛开始。

## 五、启动顺序检查清单

| 顺序 | 节点 | 检查项 |
|---|---|---|
| 1 | competition_control | 终端显示 "等待启动..." |
| 2 | robot_with_imu | `rostopic list \| grep /odom` 能查到 |
| 3 | navigation_shoot | `rostopic list \| grep /move_base_simple/goal` |
| 4 | usb_cam + shoot | `rostopic list \| grep /usb_cam/image_raw` |
| 5 | ar_track_alvar | `rostopic list \| grep /ar_pose_marker` |
| 6 | find_object_2d | `rostopic list \| grep /object_position` |
| 7 | 语音 | `rostopic list \| grep chinese_topic` |

用 `rqt_graph` 可视化检查所有连接是否正常。

## 六、常见问题

| 现象 | 排查 |
|---|---|
| 找不到激光雷达 | USB 线插错了，换到 NUC 左上方 USB |
| 找不到射击模块 | 橙色 USB 线没插好 |
| 小车不移动 | `rostopic echo /cmd_vel` 检查是否有速度指令 |
| 导航不工作 | 地图是否加载、AMCL 初始位姿是否设置 |
| 模板匹配不识别 | 环形靶模板序号和代码里 `data.z == 34` 是否对应 |
| AR 标签不识别 | `rosrun rqt_reconfigure rqt_reconfigure` 调 ar_track_alvar 参数 |
| 多次打不准 | 检查枪口物理偏移，微调 `competition_control.py` 里的 `-320` 偏移量 |
| 终点进不去 | 调大 `_slide_into_end()` 里的速度或持续时间 |
| 语音识别失败 | 麦克风是否插好、背景噪音是否过大 |
