## 二、四状态机

### WAIT_START

```
1. 发布 /initialpose (从 YAML start_pose)
2. 设置 YAML 默认 target_id (rotating=1, moving=6)
3. 等待人工按 Enter 确认
4. → VOICE_RECV
```

### VOICE_RECV

```
1. 触发语音识别 (publish audio_topic ×2)
2. 检查 target_id 是否已知:
   - 已知 (YAML 已设) → 跳过 18s 等待
   - 未知 → sleep(18) 等待语音识别结果
3. 回退到 YAML 默认值 (若仍为 None)
4. → NAV_LOOP, current_point_index = 0
```

### NAV_LOOP

```
while point_index < len(route_points):
    取当前点
    按 type 分发:
      'back_y_only' → _handle_back_y_only
      'relay'       → _handle_relay
      'task'        → _handle_task
      'end'         → _handle_end
    point_index += 1

所有点遍历完 → FINISH
```

### FINISH

```
cancel move_base, 发送零速 cmd_vel, 退出循环
```

## 三、四种点位类型算法

### 3.1 back_y_only — 安全后退点

**目的**: 射击后先直线退到安全 y 线，再横向移动。防止从射击位直接斜切撞围挡。

**算法** (三层兜底):

```
第1层: goto(x, y, timeout=8s, tol=0.15)
        move_base 主动导航到目标点
        cancel move_base
        ↓
第2层: 若未达标 (robot_y > target_y + 0.08)
        → goto 重试一次
        ↓
第3层: cmd_vel 兜底
        → _cmd_vel_to_y(target_y, speed=-0.10, timeout=5s)
        直接发布 Twist().linear.y = -0.10
        用全向底盘侧向移动
        ↓
结果: y_ok → 继续 / 仍失败 → 报错 [BACK_Y] ALL FAIL, 强制继续
```

**到达条件**: `robot_y <= target_y + BACK_Y_TOL` (0.08m)

**不做**: yaw 旋转、位置精调、射击

### 3.2 relay — 途经安全点

**目的**: 退到安全 x 走廊内 (离围挡有安全距离)，然后计算到下一个射击点的动态出发航向。

**算法**:

```
1. publish /move_base_simple/goal → target(x, y)
2. 轮询等待到达:
   到达条件 (两个同时满足):
     a) y_ok:  robot_y <= target_y + RELAY_Y_TOL (0.08m)
     b) x_safe: SAFE_X_MIN(0.10) <= robot_x <= SAFE_X_MAX(0.45)
3. cancel move_base, 停车
4. 计算动态出发航向:
     heading_deg = atan2(next_y - robot_y, next_x - robot_x)
5. 粗修旋转:
     _rotate_to_yaw(heading_deg, tol=25°, timeout=1.5s)
     途经点不需要精确朝向，只要大致方向对
```

**为什么不用 dist 判定**: 途经点的作用是退到安全 x 线。dist 判定会把机器人拖到坐标点附近，而坐标点在左侧围挡附近时容易碰撞。y+x 双条件确保机器人先"越过安全线"。

### 3.3 task — 射击点

**目的**: 精确到达射击位置和朝向，然后执行射击。

**完整流程** (5 步):

```
Step 1: 粗定位
  goto(x, y, timeout=15s, tol=0.12)
  cancel move_base

Step 2: 预检 (goto 后)
  计算 d_pre = dist(robot, target)
  计算 yaw_err_pre = |robot_yaw - task_yaw|
  若 d_pre <= 0.08 AND yaw_err_pre <= 15°:
    → 跳转到 Step 4 (跳过精调和旋转)
  否则:
    → 继续 Step 2a

Step 2a: XY 精调 (仅位置)
  _fine_adjust_xy(x, y, target_yaw_deg=task_yaw)
  内部算法 (最多 3 次尝试):
    - P 控制器: 先旋转面向目标方向，再前进
    - |yaw_err| > 0.3 rad → 纯旋转 angular.z = clamp(yaw_err, ±0.5)
    - |yaw_err| <= 0.3 rad → 前移 + 微调 linear.x = clamp(d*0.3, ±0.08)
    - Yaw 漂移保护: 若 yaw 偏离 task_yaw 超过 20°, 立即 abort
    - 成功条件: dist <= 0.06m
    - 超时: 10s/次

Step 2b: Yaw 旋转 (精修)
  若 |yaw_err| <= 15°:
    → 跳过旋转 (yaw 已经够好了)
  否则:
    → _rotate_to_yaw(task_yaw, tol=15°, timeout=5s)

Step 3: TASK 入口最终检查
  计算 d_final, yaw_err_final
  条件: d_final <= 0.08 AND yaw_err_final <= 15°
  不满足 → [TASK] FAIL, 跳过该点

Step 4: 执行射击
  Dry-run (无 /dev/shoot):
    → 立即标记 shoot_ok=True
  真机:
    按 target_type 设置对应 shooting flag:
      circular → should_attack_circular = True
      rotating → should_attack_rotating = True
      moving   → should_attack_moving = True
    等待 _wait_for_shoot(flag, timeout=15s)
    射击回调自动瞄准 + 开火
```

**关键保护机制**:

| 机制 | 参数 | 作用 |
|------|------|------|
| **Yaw 漂移保护** | 20° | fine_adjust_xy 期间若 yaw 偏离超过 20°, 立即停止 |
| **Yaw 跳过** | 15° | 若 goto 后 yaw 已经很接近目标, 不执行 _rotate_to_yaw |
| **位置跳过** | 0.08m | 若 goto 后位置已经很接近, 不执行 _fine_adjust_xy |
| **TASK 门禁** | 0.08m + 15° | 射击前最终验证, 不通过则标记 FAIL 不射击 |

### 3.4 end — 终点

**算法**:

```
1. 若有 pre_point:
     goto(pre_point, timeout=60s, tol=0.12)
     cancel move_base
2. _slide_to_point(end_x, end_y, speed=0.08, timeout=6s):
     cmd_vel 低速滑入 (绕过 costmap 阻挡)
     linear.x = clamp(dx * 0.5, ±0.08)
     linear.y = clamp(dy * 0.5, ±0.08)
     提前接受: dist <= 0.08m → 立即成功
     超时: dist <= 0.08m 也返回 True (宽松接受)
3. → FINISH
```

## 四、底层导航方法

### 4.1 goto() — 粗定位

```
1. 构造 PoseStamped (frame='map')
2. publish 到 /move_base_simple/goal (等同 RViz 2D Nav Goal)
3. 轮询 TF 获取 robot pose, 计算 dist
4. dist < tol → 返回 True
5. timeout → cancel move_base, 返回 False
```

**设计理由**: 使用 topic 而非 actionlib, 因为 actionlib 在 costmap 阻挡时可能提前 abort。

### 4.2 _fine_adjust_xy() — XY 精调

```
P 控制器 + 方向合成分解:
  dx = target_x - robot_x
  dy = target_y - robot_y
  target_dir = atan2(dy, dx)
  yaw_err = target_dir - robot_yaw

  若 |yaw_err| > 0.3 rad:
    纯旋转: angular.z = clamp(yaw_err, ±0.5)
  否则:
    前进 + 微调:
      linear.x = clamp(d * 0.3, ±0.08)
      angular.z = clamp(yaw_err * 0.5, ±0.3)

成功: dist <= pos_tol (默认 0.06m)
最多 3 次尝试, 每次 10s
```

### 4.3 _rotate_to_yaw() — 原地旋转

```
P 控制器:
  angular.z = clamp(yaw_err * 1.0, ±0.5)

成功: |yaw_err| < tol_deg
超时: 默认 5s
```

### 4.4 _slide_to_point() — 终点滑入

```
全向 cmd_vel 控制:
  linear.x = clamp(dx * 0.5, ±speed)
  linear.y = clamp(dy * 0.5, ±speed)

绕过 costmap, 低速滑入终点区域
```

### 4.5 _cmd_vel_to_y() — Y 方向兜底驱动

```
纯 cmd_vel 侧向移动:
  Twist().linear.y = speed (-0.10 m/s)

用于 back_y_only 的第三层兜底
```

## 五、射击回调架构

沿用 shoot_2025.py 的 callback-driven 模式:

```
模块级 global 变量 (线程间通信):
  should_attack_circular  = True/False
  should_attack_rotating  = True/False
  should_attack_moving    = True/False
  target_id_rotating      = int
  target_id_moving        = int

三种靶子:
  circular: /object_position 回调 → P 控 angular.z = -0.02 * offset_x
  rotating: /ar_pose_marker 回调 → P 控 angular.z = -1.0 * ax
  moving:   /ar_pose_marker 回调 → P 控 angular.z = -0.95 * ax

开火: serial.write(0x55 0x01 0x12...) → sleep(0.09) → serial.write(0x55 0x01 0x11...)
```

## 六、竞赛监控 (competition_monitor)

独立节点, 5Hz 运行:

| 检测项 | 参数 | 触发动作 |
|--------|------|----------|
| 边界 | field_half=1.8m | publish /voiceWords "超出场地边界" |
| 卡死 | stuck_timeout=20s | publish /voiceWords "状态卡死" |
| 总时间 | total_time=120s | publish /voiceWords "比赛时间到" |
| 运动 | delta > 0.005m | 记录最后运动时间 |

## 七、坐标与 TF

```
坐标系: map (AMCL 校正后的绝对坐标)
位置源: TF map → base_link (不信任 odom)
Yaw 源: tf.transformations.euler_from_quaternion

TF 查询超时: 0.5s (pose), 0.3s (yaw)
Yaw 误差归一化: 始终归一化到 [-pi, pi]
```

## 九、日志标签体系

| 标签 | 来源 | 含义 |
|------|------|------|
| `[TASK_PRE]` | task | 射击点预到达状态 (goto 前) |
| `[ARRIVE]` | goto() | 粗定位成功/超时 |
| `[FINE_ADJUST_XY]` | _fine_adjust_xy() | xy 精调过程 |
| `[ROTATE]` | _rotate_to_yaw() | 原地旋转 |
| `[TASK]` | task | 射击任务结果 (Done/Fail/Skip/FAIL) |
| `[BACK_Y]` | back_y_only | 后退点状态 |
| `[RELAY]` | relay | 途经点到达/出发航向 |
| `[END]` | end | 终点滑入 |
| `[CMD_VEL_Y]` | _cmd_vel_to_y() | cmd_vel 兜底驱动 |
